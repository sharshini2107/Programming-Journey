## Doubts

1. What is the difference between == and .equals()?

**Answer:**  
`==` compares references (or primitive values), whereas `.equals()` compares the actual content of objects such as Strings.

---

2. Why do we use the Scanner class?

**Answer:**  
The Scanner class is used to read input from the user through the keyboard.

---

3. What is the difference between while and do-while loops?

**Answer:**  
A `while` loop checks the condition before executing the loop body.  
A `do-while` loop executes the body once before checking the condition.

---

4. When should we use if-else instead of switch?

**Answer:**  
Use `if-else` for complex conditions and ranges.  
Use `switch` when comparing a single variable against multiple fixed values.
